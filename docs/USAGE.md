# 知识图谱使用手册

本地优先的 Markdown 笔记 + 知识图谱应用：笔记之间用 `[[双链]]` 关联，
把「谁做过什么、一个问题牵涉哪些工作」看成一整张网。全部笔记存在你自己选的
目录里（每篇一个 `.md` + 根目录一个 `meta.json`），可直接用 Obsidian 打开。

本文档面向**使用者**；安装与启动细节见 [免安装网页使用说明](WEB_PORTABLE.md)，
开发者请看 [README](../README.md)。

## 启动与首次使用

1. 完整解压 `knowledge-graph-web-<版本>-windows-x64.zip` 到一个可写的固定文件夹。
2. 双击 `启动知识图谱.wsf`（无窗口运行），浏览器打开 `http://127.0.0.1:4173`。
3. 首次启动使用程序文件夹里的 `data/vault` 存笔记；在顶栏可改选自己已有的笔记目录
   （vault），或在 `配置.json` 里固定 `"vaultDir"`。
4. 关闭服务：双击 `停止知识图谱.wsf`。

没有网络也能记笔记、看图谱、读本地 PDF；只有在线文献检索、DOI/arXiv 导入和
配置后的 AI 功能需要联网。

## 三种视图布局

顶栏左侧可切换：

- **笔记**：单栏流式阅读/编辑当前笔记，整篇随页面滚动。
- **图谱**：整屏知识图谱，看全部笔记的关联结构。
- **并列**：三栏并排——左侧图谱、中间笔记详情与正文、右侧可展开的 PDF 面板。
  图谱里单击节点会直接打开该笔记；打开任何笔记也会让图谱自动聚焦对应节点。

## 笔记

- **新建**：侧栏「新建笔记」，五种类型：人物 / 项目 / 技能 / 学习 / 其他
  （各有专属颜色，落盘时按类型分文件夹）。
- **编辑**：所见即所得编辑器，支持 Markdown 表格、上下标、代码块与 LaTeX 公式
  （`$…$` 行内、`$$…$$` 块级）。顶部视图切换条可在 编辑 / 预览 / 分屏 之间切换。
- **自动保存**：编辑后延迟自动写盘；切换笔记或视图前内容已落盘。
- **双向同步文件**：在应用外直接改 `.md` 也会被拉进应用；两边同时改会弹冲突对比，
  由你选择保留哪一边。
- **未纳管的 md**：vault 目录里不属于本应用的 Markdown 文件不会被读写，
  只在界面提示「另有 N 个未纳管 md」。

## 双链与标签

- 输入 `[[` 自动补全笔记标题，回车建立双链；阅读视图里点 `[[标题]]` 直接跳转。
- 双链会在图谱里生成连线；删除链接文字即删除这条边。
- `#标签` 可写在正文任意位置；带 `前缀:` 的标签（如 `年份:2024`）在筛选时按前缀分组。

## 图谱视图

- **筛选**：按 类型 / 年级 / 标签 组合筛选；标签按 `前缀:` 分组，组内「或」、跨组「与」。
- **交互**：单击节点选中、再次单击打开笔记；右键聚焦，按到焦点的跳数逐层虚化。
- **力参数**：节点斥力、双链引力、连线长度、中心聚集四根滑杆，另有
  紧凑 / 标准 / 宽松 / 极散 预设；参数本地记忆，改完可「重新布局」。
- **缩放与标签**：放大时节点文字变大（封顶 2 倍）；缩得很小时自动只标连接数最多的
  大节点（工具栏也有「只标大节点」强制开关）。
- **文献聚类**（「仅文献」筛选档，默认开）：文献先聚成几个簇，单击簇铺开它的成员、
  右键返回；成员按所属标签枢纽上色，偏题的成员自动虚化。关闭「文献聚类」开关
  则铺开全部文献节点。

## 文献库（Zotero 核心能力）

切换到「文献」视图是一张可排序 / 搜索的表格（分类列为折叠树，按 ▸ 逐级展开）。

- **导入文献**：
  - DOI 一键导入（CrossRef / DataCite）；
  - arXiv 一键导入；
  - BibTeX / RIS 粘贴批量导入（citekey 自动生成、撞名追加后缀）；
  - 「同步 Zotero 分类」：从本机 Zotero 库读取分类与标签，更新已有笔记（不新建）。
- **复制引用**：行内「⋮」菜单，支持 **GB/T 7714-2015**（国标顺序编码制）/ **APA** / BibTeX。
- **插入 Word 引用**：复制 RTF 域代码（`ADDIN ZOTERO_ITEM`，与 Zotero 兼容），
  粘进 Word 是可更新的真实域（Alt+F9 可查看域代码）；也可一键复制整份参考文献表。
- **命令行批量同步**（全量扫描、可新建笔记，先 dry-run 再 `--apply`）：

  ```bash
  npm run zotero:sync -- --vault "<笔记目录>" --db "C:\Users\<你>\Zotero\zotero.sqlite"
  # 确认无误后：
  npm run zotero:sync -- --vault "<笔记目录>" --db "C:\Users\<你>\Zotero\zotero.sqlite" --apply
  ```

- **本地 PDF 认回**：`npm run pdf:link -- --vault "<笔记目录>" --db "<zotero.sqlite>"`
  （先 dry-run，`--apply` 才写盘），把本机 PDF 的绝对路径记进笔记，不复制不移动文件。
- **去重**：`npm run dedupe:vault -- --vault "<笔记目录>"` 预览合并方案，`--apply` 写盘；
  合并只做并集，不丢数据。

## PDF 阅读工作台

- 从文献表点 **PDF 徽标**（徽标本身就是按钮，单击即开）进入全屏双栏阅读：
  左侧翻页 / 缩放 / 搜索 PDF，右侧编辑或预览文献笔记。
- 选中 PDF 原文可建立**页码链接**；点击笔记里的链接可跳回原文位置。
- 高亮标注存在 vault 的 `attachments/` 子目录里；也可随时改用系统 PDF 阅读器。
- PDF 打开优先级：笔记里记录的本地路径 → Zotero 附件（支持去重后的多 key 回退）→
  按标题在授权目录里兜底匹配 → 都没有时用 `zotero://` 在 Zotero 里定位条目。
- 详情页附件区的「本地 PDF / Zotero PDF」条目带第一页快照，点击就地阅读；
  「全屏阅读」进入上面的工作台。

## AI 统筹面板

顶栏「AI 统筹」= 自由提问 + 四个任务模板。

- 上下文范围可选：不附 / 当前笔记 / 当前笔记 + 双链与反链（超长自动截断）。
- 支持 Kimi 与 DeepSeek 两家（DeepSeek 读取本机已配置的 key，或用环境变量
  `DEEPSEEK_API_KEY`）。
- **自由提问只读**：AI 不会改你的笔记。回答里的 `[[标题]]` 可点开对应笔记。

## 数据、备份与迁移

- 笔记 = 每篇一个 `.md`（frontmatter 存元数据），根目录一个 `meta.json` 索引；
  `md` 是唯一事实来源，`meta.json` 丢了也能靠 md 完整还原。
- 跨机器迁移：顶栏「导出 / 导入 JSON」，或直接复制整个 vault 目录。
- 所有批量写盘入口（Zotero 同步、去重、PDF 认回）都遵循同一套安全规则：
  dry-run 不动盘、`--apply` 先整库备份到 `.backups/`、只增不删、未纳管 md 不碰、
  索引里读不到的文件直接中止而不是静默丢数据。
- 写入门禁：遇到格式版本超出当前客户端能力的笔记会自动只读，避免旧版本
  回写丢字段。混用新旧版本后如果界面异常，按 Ctrl+F5 强刷。

## 常见问题

- **起不来 / 端口被占**：看 `data/temp/web-server.log`；或在 `配置.json` 改 `port`。
- **`.wsf` 被安全软件拦住**：改用 `启动知识图谱.cmd`（会保留一个命令窗口，关窗即停）。
- **浏览器显示旧界面**：Ctrl+F5 强制刷新。
- **`node.exe` 报 `0xc0000142`**：把整个目录移到不含中文的短路径再启动；
  企业受控目录也会触发，换一个普通可写目录即可。
- **Zotero 库找不到**：`配置.json` 里显式写 `"zoteroDb"` 指向 `zotero.sqlite` 的完整路径
  （注意：是 Zotero 数据目录下那个，不是 `%APPDATA%` 里的 profile 目录）。
- **这是本地网页，不是在线站点**：`127.0.0.1` 只在本机有效；把程序文件夹发给别人时
  不要带上自己的 `data` 目录。
