## 一、已确认的产品方向

在笔记页面嵌入「研究追问」助手，不做泛用聊天机器人，也不以自动打标签为核心。

核心闭环：用户手动保存笔记 → 点击「完成笔记 · 研究追问」→ 生成 3 个有内容针对性的研究问题 → 用户回答、收藏、跳过或稍后处理 → 用户确认后才可插入笔记 → 本地问题库逐步学习用户偏好。

默认突出一个最值得回答的问题，其余问题折叠，避免形成审问清单。回答先作为草稿，不自动修改或保存正文，保留现有手动保存习惯。

### 问题类型

- 概念澄清：关键术语、变量、范围是否明确。
- 证据核查：结论是否有数据、引文或实验支撑。
- 方法审查：对照、参数、样本、实验条件是否完整。
- 边界与反例：结论在什么情况下可能不成立。
- 知识连接：与已有笔记或研究问题有什么联系。
- 下一步行动：最值得补做的一个实验或阅读任务。

禁止泛泛提问；问题必须引用当前笔记里的具体对象、结论或缺口。每道题附一句「为什么值得问」。
