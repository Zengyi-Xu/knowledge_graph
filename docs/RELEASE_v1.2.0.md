# v1.2.0 · Windows x64 免安装网页版

## Summary

本版本把最新版知识图谱做成可直接分享的本地网页文件夹。下载 ZIP、完整解压、双击 `启动知识图谱.cmd` 即可使用；附带 Node 和 Windows x64 SQLite 运行库，无需安装 Node、npm、Electron 或 NSIS 安装程序。

- 保留 Markdown 笔记、双链图谱、文献表、引用和 Zotero 只读同步能力。
- 提供双栏 PDF 阅读与笔记工作台、页码摘录链接和标注；支持 `localPdf` 与多个 Zotero key 回退。
- 所见即所得编辑和相关资源随包提供，普通笔记编辑不依赖 CDN。
- 首次使用独立的 `data/vault`；可配置已有笔记库、Zotero 数据库与 PDF 授权目录。
- 本地服务仅监听 `127.0.0.1`，使用来源校验和访问令牌；不携带开发者的真实笔记、数据库、PDF 或密钥。
- 随包提供使用说明、运行环境许可证及构建清单；Release 提供 ZIP 的 SHA-256 校验值。

## 使用

下载 `knowledge-graph-web-1.2.0-windows-x64.zip`，完整解压后双击 `启动知识图谱.cmd`。默认浏览器打开 `http://127.0.0.1:4173`；保留命令窗口即可继续使用。

Windows x64；这是本地网页文件夹，不是可直接分享的公网网址。在线检索与 AI 功能仍需要网络和用户自己的配置。
更新前停止旧服务，保留自己的笔记目录与配置；网页仍显示旧界面时按 Ctrl+F5。
