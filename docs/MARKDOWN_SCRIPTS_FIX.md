# 上下标修正记录

日期：2026-10-08

## 原因

1.0.1 支持 HTML `<sub>` / `<sup>`，不支持 Typora 简写，也不会把普通文本 `σ_w` 自动转换为下标。

Typora 简写：下标 `σ~w~`、上标 `x^2^`；`~~文字~~` 仍是删除线。

## 本次改动

- `src/lib/md.ts`：支持单波浪线下标和尖号上标，保持代码、链接和删除线优先级。
- `scripts/md-selftest.mjs`：增加解析回归测试。
- `scripts/md-scripts-render-test.tsx`：验证真实 React 渲染输出。
- 本地笔记只转换已核实的 5 处 `σ_w`、`σ_param`、`σ_τ`、`τ_d`，涉及 2 篇笔记。保留 ID 和时间戳，修改前创建本地 JSON 备份。
- 不修改代码中的变量名；不引入 `_` 自动转换或公式渲染引擎。

支持 `x~a\ b~` 这样的转义空格；未转义的空格不在简写范围内。复杂公式后续应单独接入数学渲染器，不能把此次修改理解为 LaTeX 支持。

## 活动数据与版本

修改仓库 `public/notes.json` 不会覆盖已存在的 localStorage 笔记。当前软件中的对应正文需要自行修改，不能直接反复导入全部 JSON，因为现有导入是追加，会产生重复笔记。

修改示例：

```markdown
写入噪声 σ~w~
器件间失配 σ~param~
保持时间 τ~d~
保持离散 σ~τ~
平方 x^2^
```

既有 1.0.1 EXE 不会自动获得此次代码修改。新功能需要重新打包，建议后续发布 1.0.2；本次没有重打包或更新 GitHub Release。

## 与移动端开发协调

此次不修改移动端工作的 `NoteEditor`、`NoteList`、`PreviewContent`、`index.css`。合并移动端时保留解析器的新语法与测试。

个人笔记及其备份不得上传公开仓库。后续公开发布只带程序代码、无个人信息的测试和示例。
